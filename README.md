# Codemotion 2012 — Sphinx: Open Source Search Server

Slide e materiali del talk presentato da **Matteo Baccan** a [Codemotion Roma 2012](https://www.codemotion.com/).

## Abstract

Sporchiamoci le mani con un'alternativa a Lucene e MySQL. Un prodotto OpenSource, portabile, veloce, attento alle prestazioni e ai consumi di spazio e memoria.

Il talk esplora le funzionalità di **Sphinx Search**, motore di ricerca full-text open source ad alte prestazioni, applicato a casi reali con PHP e Java.

## Argomenti trattati

- Sphinx come alternativa a Lucene e MySQL full-text
- Architettura e distribuzione del carico
- Hotswap di indici senza downtime
- Accesso via JDBC a MySQL e Sphinx con la stessa interfaccia
- Gestione di indici dinamici e statici
- Query, subquery e strategie di ricerca avanzate
- Tecniche per indicizzare milioni di documenti in modo efficiente
